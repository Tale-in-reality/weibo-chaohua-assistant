文案库

「已确认」的才是风格来源 —— 写文案时只取这部分。从微博导入的先落「未确认」，你核对后再确认。

需要先在「推送」页扫码登录。只收本人原创，纯转发/水贴会跳过；按 mid 去重，重复导入不会重复。 导入的先落「未确认」，你确认后才进「已确认」。
后台跑：每翻 20 页休息一下再继续，一直翻到扫完上面的日期范围。 休息填 0 ＝ 完全不额外休息，只靠每请求 1~2.5 秒的间隔控节奏。

风格档案

让模型读全部文案，把你的「说话规律」写成一份说明书；每次写文案都会注入它。加了新文案后点「重新生成」即可更新。

本地模型正在通读全部文案并提炼规律，可能要几十秒到几分钟…
💡 本地 7B 提炼的档案偏弱。更省事的做法：点「复制全部文案」→ 粘给云端强模型（ChatGPT / Claude）→ 让它提炼「句式 / 标点习惯 / 高频词 / 语气 / 长度 / 禁忌」→ 粘回上面的框 → 保存。
配合上面的档案一起注入。样本按关键词检索（同类型加权）挑，越多越慢。

术语

知识核心：词条 = 术语 + 释义。这是写文案时「懂梗」的唯一保证来源。

候选从哪来：从文案库抽（jieba 分词 + 模型筛）或 从超话帖抽（模型识别）。 机器只提候选，含义你来定。

事件

每条帖子是一条事件（点标题展开全文）；「📋 速览」把整批内容压成要点，推送推的就是它。

推送

桌面弹窗。抓到新速览会立刻推一次，之后按设定间隔检查（只推没推过的，不重复）。打开 app 时若开着「定时抓取」，会按距上次抓取的空档自动补抓一次 —— 进度在下面和「概览」页都能看到。

⚠️ 用小号扫码。登录成功会自动把 cookie 存进「设置 · 超话抓取」，长期有效，不用每次重扫。
按当前「设置 · 超话抓取」里的配置抓一次；抓到新帖会自动总结（每帖一条事件 + 一条速览）。

设置

模型、识图、超话抓取、推送频率、总结频率、开机自启。
